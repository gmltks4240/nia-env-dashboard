# Scope 3 출장 배출량 자동산정 — 1단계(철도) 설계

- 작성일: 2026-11-12
- 상태: 1차 구현 완료 (구현하며 바뀐 점은 §11)
- 용도: **대외 공시·검증 대응** (행 단위 추적, 가정·제외 항목 문서화 필요)

## 1. 목표

출장 엑셀을 올리면 자유 입력된 출발지·목적지를 AI가 표준 지점으로 분류하고,
정해진 규칙으로 Scope 3 카테고리 6(출장) 배출량을 산정해 대시보드에 표시한다.

성공 기준:

1. 관내출장 엑셀(연도별 시트)을 올리면 철도 행 전체가 행 단위로 산정된다.
2. 모든 행에 판정 등급(A~D)·적용 거리·계수·근거가 남아 한 건씩 추적할 수 있다.
3. 같은 파일을 다시 올리면 같은 결과가 나온다(AI 결과는 사전에 고정).
4. AI 호출이 실패해도 산정이 멈추지 않는다.
5. 산정 엔진이 2026-11-12 시산값(§9)을 재현한다.

## 2. 범위

| 단계 | 내용 | 이 문서 |
|---|---|---|
| 1단계 | 업로드 → 장소 사전(AI) → 철도 산정 → Scope 3 화면·검토 화면 | 대상 |
| 2단계 | 자가차량, 국내 항공, 버스, 선박 | 대상 아님 (계수 협의 필요) |
| 3단계 | 국외 항공 | 대상 아님 (계수·경유지 기준 협의 필요) |

장소 사전·행별 저장·업로드 묶음·검토 화면은 교통편에 묶이지 않게 만들어 2·3단계에서 재사용한다.

1단계에서 하지 않는 것: 숙박 배출, 철도 외 교통편 산정, 좌석 등급별 계수.

## 3. 확정된 산정 규칙

사용자와 합의한 내용이다.

### 3.1 경계

- GHG Protocol Scope 3 카테고리 6(출장).
- 공용차량은 제외한다(연료가 Scope 1 차량연료에 이미 포함).
- 차량동승은 0으로 본다(운전자 행에 포함).

### 3.2 행의 의미

- 한 행 = 출장 1건(1인). 출발지→목적지는 가는 방향만 적은 것이고 기본은 왕복이다.
- 한 출장의 철도 이동은 **대개 왕복 1회**다. 상한은 아니다(2026-11-17 정정): 출장 기간이 길면 2회 이상일 수 있다.
  교통비가 왕복 운임(등급 A·B·C)의 정확히 n배(2~5)이고 출장 일수가 n일 이상이면 왕복 n회로 산정한다(174,000원 · 2일 이상 → 왕복 2회).
  일수가 모자라거나 일수를 모르면 일수만큼(모르면 1회)만 산정하고 "횟수 확인 필요"로 표시한다. 121,800원은 특실 왕복 1회다.
- 교통비가 구간 왕복 운임의 절반 수준이면 편도다.
- **교통비 0원은 미이동**으로 보고 제외한다. 제외 건수는 따로 집계해 공시 주석에 쓴다.
- "서울→서울"에 대구–서울 편도 운임이 찍힌 행은 동대구→서울 편도 1회다(선이동 관행).
- 특실은 임원 등 극히 일부가 이용한다. 계수는 좌석 등급을 구분하지 않으므로
  특실 운임은 편도/왕복 판정에만 쓴다.

### 3.3 철도 배출계수 (기관 협의값)

| 구분 | kgCO₂eq/인·km | 적용 |
|---|---|---|
| KTX 경부선 | 0.0219 | 기본 |
| KTX 호남선·기타 | 0.0219 | 경부선 준용 |
| KTX 강릉선 | 0.0716 | 출발지·목적지가 강릉·평창·진부·횡성·둔내 권역일 때 |
| SRT | 0.0219 | 별도 인증계수 확인 전 대용 |

열차 종류는 파일에 없다. KTX·SRT·일반열차를 구분하지 않고 0.0219를 쓰며,
원주·춘천은 강릉선이 아닌 것으로 본다.

### 3.4 거리

- 한국철도공사 철도운행거리(2024-09-01) 정규화 1,412행을 쓴다.
- 같은 역쌍에 거리가 여럿이면 표1(고속선 대표 경로)을 쓴다. 동대구–서울 286.7km.
- 수서 구간은 코레일 원본에 없어 참고값을 쓴다(수서–동대구 269.2, 수서–서대구 261.8).
  그 외 수서–X는 서울–X − 17.5km, 서대구–X는 동대구–X ± 7.4km로 추정하고 "거리 추정"으로 표시한다.

### 3.5 판정 등급

행마다 아래 순서로 판정하고 등급을 남긴다.

| 등급 | 조건 | 거리 |
|---|---|---|
| A 업무상 확정 | 교통비가 판정기준표(`출장운임_판정기준` 14개 운임)와 일치 | 판정기준표의 거리 |
| B 운임표+구간 일치 | 교통비가 운임표의 편도 운임 또는 같은 도시쌍 두 구간 합과 일치하고, 장소 사전으로 얻은 출발·목적 도시가 그 구간과 일치 | 해당 구간 공식거리 |
| C 운임표만 일치 | 교통비는 운임표와 일치하나 출발·목적 도시로 구간을 확인하지 못함. 후보 거리 편차 5% 이내일 때만 | 후보 구간 거리 |
| D 추정 | 위에 해당 없음. 출발·목적 도시의 구간이 있으면 그 공식거리를 쓰고, 교통비가 기준 편도 운임의 1.5배 미만이면 편도·이상이면 왕복. 구간도 모르면 교통비 ÷ 151.7원/km(43,500 ÷ 286.7), 상한 860km | 구간 거리 또는 운임 역산 |

보조 규칙:

- 특실 운임 = KTX 일반실 × 1.4, 100원 단위 반올림. 파일 수치(43,500 → 60,900)와 서울–부산 4개 경로(59,800 → 83,700 · 59,400 → 83,200 · 53,900 → 75,500 · 48,800 → 68,300,
  위키백과 '한국고속철도' 2022-12-28 기준)로 확인했다. 코레일 공식 특실 운임표와의 대조는 미완료다. 후보가 여럿이면 일반실 > 특실, 공식거리 > 추정거리, KTX > SRT 순으로 고른다.
- 판정기준표의 편도 운임(SRT 36,900~37,300, 오송 환승 43,300)은 두 구간 합 계산의 재료로도 쓴다
  (예: 80,400 = 43,500 + 36,900).
- 목적지·경유지가 여러 도시면 D등급에서는 가장 먼 구간을 쓴다.
- 강릉선 권역 행(2026-11-17 변경): 타는 역·내리는 역을 추정한다. 강릉선 쪽은 장소 글자의 역(강릉·진부·평창·둔내·횡성, 여럿이면 가장 먼 역, 글자에 없으면 강릉),
  반대쪽은 그 도시에서 서울까지 간 뒤 강릉선으로 갈아탄 것으로 본다(대구 → 동대구-서울 286.7km + 서울-역).
  계수는 구간별로 적용한다: 서울까지 0.0219, 서울–강릉선 역만 0.0716. 등급은 D(추정)로 둔다.
  - 역별 거리(서울역 기점): 횡성 126.0 · 둔내 146.6 · 평창 166.6 · 진부 182.9 · 강릉 223.2km. 국토교통부고시 제2017-428호 철도거리표(위키백과 '강릉선 KTX' 역 목록에서 옮김),
    코레일 운영노선 '원주~강릉 120.7km'와 대조. 코드의 `TRIP_GANG_KM`에 둔다(기준표 엑셀에 강릉선 행이 생기면 그쪽으로 옮긴다).
  - 편도·왕복: 예상 편도 운임(서울까지의 운임 + 27,600원 × 역 거리 ÷ 223.2)의 1.5배 미만이면 편도. 27,600원은 서울–강릉 일반실(2017년 보도) — 역별 공식 운임표는 미확보.
  - 계수 원칙(2026-11-17 사용자 결정): **강릉선(서울–강릉선 역) 구간만 0.0716, 그 밖의 모든 철도는 경부선 기준 0.0219**.
  - 동해선 직통(동대구–강릉, 2025-01-01 개통)은 따로 추정하지 않는다. 2023~2026 실제 자료의 강릉선 권역 철도 17건(0원 제외) 중 서울 경유보다 훨씬 싼 금액이 0건이었다.
    다만 2026-09-21 대구→강릉 2일 출장 3건(75,800 · 78,700 · 78,700원)은 서울 경유 왕복(133,200원)·포항 경유 왕복(77,600원) 어느 쪽과도 맞지 않아 서울 경유 편도로 잡힌다 — 사용자 확인 대기.
  - 반대쪽 장소를 모르면 종전처럼 운임 역산을 쓰되 상한 860km를 적용한다.

## 4. 구성요소

각 단위는 하나의 일만 하고, 아래 인터페이스로만 이어진다.

### 4.1 업로드·파싱 (브라우저)

- 기존 엑셀 업로드(SheetJS 지연 로딩)를 재사용한다.
- 출장 양식을 인식한다: 시트 제목 `관내출장현황`, 머리글 3행, 열 = 번호·시작일·종료일·박·일·출발지·경유지·목적지·교통편·왕복거리·연비·유가·교통비.
- 출력: `TripRow[]` = `{ year, seq, date, origin, via, dest, mode, fare, distKm, fuelEff, fuelPrice }`.
- 1단계는 `mode === '철도운임'`만 산정하고, 나머지 교통편은 건수만 "미산정"으로 집계한다.

### 4.2 장소 사전 (Supabase `trip_places`)

원문 장소명을 표준 지점으로 바꾼 결과를 고정 저장한다.

| 열 | 설명 |
|---|---|
| `raw` (PK) | 앞뒤 공백을 지운 원문 |
| `points` | 표준 지점 코드 배열. 복수 목적지("세종, 서울")는 여러 개 |
| `confidence` | `high` / `low` / `unknown` |
| `reason` | 한 줄 근거 |
| `source` | `seed`(사전 탑재) / `ai` / `human` |
| `updated_by`, `updated_at` | 변경자·시각 |

- 표준 지점 코드는 도시 단위다: 대구, 서울, 세종(오송), 대전, 부산, 천안아산, 김천구미, 경주, 울산, 포항,
  광주송정, 나주, 익산, 전주, 목포, 여수, 순천, 진주, 창원, 밀양, 공주, 정읍, 강릉선권역, 제주, 기타.
  도시→역 대응(서울 = 서울·용산·광명·수서 등)은 산정 엔진이 가진다.
- `source = human`인 행은 AI가 덮어쓰지 않는다.
- 초기 데이터: 현재 4개 연도의 고유 장소 3,513개를 분류해 `seed`로 넣는다.

### 4.3 AI 분류 함수 (Supabase Edge Function `classify-places`)

- 입력: 사전에 없는 원문 장소명 배열(한 번에 최대 100개).
- 처리: Claude API에 표준 지점 코드 목록을 주고, 장소마다 `points`·`confidence`·`reason`을 구조화 출력으로 받는다.
  목록에 없는 값은 거부하고 `unknown`으로 처리한다.
- 출력: `trip_places`에 `source = ai`로 기록하고 결과를 돌려준다.
- 권한: 로그인한 편집자·관리자만 호출할 수 있다(`app_role()` 확인).
- API 키는 Supabase 비밀값으로만 둔다. 화면 코드에는 넣지 않는다.
- 전송 내용은 장소명 문자열뿐이다(번호·날짜·금액·부서 미전송).
- 키가 없거나 호출이 실패하면 오류 코드를 돌려주고, 화면은 해당 장소를 `unknown`으로 두고 계속한다.

### 4.4 기준표 (Supabase `trip_ref`)

판정에 쓰는 표를 적용 기간과 함께 저장한다.

| 열 | 설명 |
|---|---|
| `kind` | `judgment`(판정기준) / `fare`(운임표) / `distance`(거리표) |
| `valid_from`, `valid_to` | 적용 기간. 출장 시작일로 고른다 |
| `data` | 표 내용(jsonb) |
| `source_note` | 출처·기준 시점 |
| `version` | 버전 문자열 |

- 초기 데이터: 판정기준 14행, KTX 주요 운임 21행, SRT 일반실 505행, 공식 운행거리 1,412행, 수서 참고거리.
- 2026-09-01 이후 운임 개편분은 새 기간의 `judgment`·`fare`로 추가한다(자료 확보 전에는 해당 행이 D등급으로 남는다).
- 철도 계수는 기존 `env_settings.ghg_factor_log`에 항목을 추가해 변경이력을 함께 쓴다.

### 4.5 산정 엔진 (브라우저, 순수 함수)

```
classifyRail(row, places, ref, factors)
  → { grade, legs, km, kmQuality, factor, kgCO2e, basis }
```

- 입력만으로 결과가 정해진다. 네트워크·시각·난수를 쓰지 않는다.
- §3.5의 순서를 그대로 구현한다. AI는 `places`를 통해서만 영향을 준다.
- `basis`는 사람이 읽는 한 줄 근거다(예: `KTX 동대구↔오송 왕복 일반`).

### 4.6 저장 (Supabase)

- `trip_batches`: 업로드 묶음. 파일명, SHA-256, 연도, 올린 사람, 적용한 기준표·계수 버전, 등급별 건수.
- `trip_rows`: 행별 결과. 원본 값 전체 + `points_origin`, `points_dest`, `place_source`, `grade`, `legs`, `km`, `factor`, `kgco2e`, `basis`, `batch_id`.
  0원 제외 행과 미산정 교통편 행도 `grade = 제외`/`미산정`으로 남긴다.
- 같은 연도를 다시 올리면 이전 묶음의 행을 지우고 새 묶음으로 대체한다(묶음 기록은 남긴다).
- 월별 집계는 `env_metrics`에 넣는다: `period = YYYY-MM`, `site = 전사`, `item = 출장_철도_kgCO2e` / `출장_철도_인km`.
  마감연도 차단·변경이력·내보내기가 기존대로 동작한다.
- 읽기는 기존 정책과 같고, 쓰기는 편집자·관리자만 가능하다.

### 4.7 화면

- **Scope 3 카드**: 폐기물 옆에 출장(철도)을 추가한다. 값 아래에 등급 비율(확정·일치·추정)을 함께 표시한다.
- **근거 패널**: 교통편별 인·km, 계수, 배출량, 산식, 제외 건수.
- **데이터 입력 탭**: 출장 엑셀 업로드. 올리면 "새 장소 n개 분류 중 → 산정 → 요약" 순서로 진행을 보여 준다.
- **검토 화면**(데이터 관리 탭): 세 목록.
  1. 확신 낮음·미확인 장소 — 표준 지점을 고르면 `source = human`으로 저장하고 영향 받는 행을 다시 산정한다.
  2. D등급 행 — 운임별로 묶어 건수 순으로 보여 준다.
  3. 제외된 0원 행 건수(연도·월별).

## 5. 데이터 흐름

## 12. 코레일 KTX 운임표 반영 (2026-11-17)

사용자가 준 한국철도공사 KTX 운임표 두 권(2025년판 · 2026년 통합 후판)을 `tools/build_trip_fares.py`로 `index.html`의 `@trip-fare` 블록에 넣었다.
원본 xls는 저장소에 넣지 않았다(사용자 보관).

- **기간별 적용**: 출장시작일이 2026-08-31까지면 [옛 기준표 + 2025년판], 2026-09-01부터면 [2026년판]만 쓴다.
  9월 이후에는 옛 판정기준(87,000 → A 등)과 SRT 운임표를 쓰지 않는다. 9월 이후 A등급에 해당하는 판정기준은 아직 없다(기관 기준이 정해지면 추가).
  날짜가 없는 행은 옛 운임으로 본다.
- **범위**: 거리표에 있는 역(과 수서·서대구)끼리의 운임만 넣었다 — 2025년판 284행, 2026년판 410행. 전라선·경전선·동해선·중앙선 역은 거리표가 없어 아직 빠져 있다.
- **특실**: 산식(× 1.4) 대신 운임표의 금액을 쓴다. 특실 = 운임 + 요금이고 요금은 2025년판에서 운임의 40%(최저 4,800원), 2026년판에서 약 45%(최저 3,400원)다.
  × 1.4 산식은 운임표에 없는 옛 기준표 행(동대구–용산 43,200 · 43,800 등)에만 남아 있다.
- **강릉선**: 서울–횡성 13,900 · 둔내 16,800 · 평창 19,700 · 진부 21,900 · 강릉 27,600원(일반실(A), 두 해 같음).
  교통비가 [서울까지 운임 + 강릉선 역 운임]의 편도·왕복과 정확히 같으면 B, 아니면 D(역 거리는 같게 적용).
- **운임 대조**: 운임표가 커져 우연히 같은 금액이 늘었으므로, 금액이 가리키는 구간을 편도 운임 하나 → 같은 구간 왕복 → 서로 다른 두 운임의 합 순으로 처음 나오는 것만 쓴다.
- **옛 운임표 대조**(2026-11-17): 사용자가 준 더 이전 판(신경주·부발~충주 수록, 2022~2023년으로 추정) 1,116행을 2025년판과 비교했더니 **일반실·특실 금액이 모두 같았다**(옛 판에만 있는 금액 0개).
  2025년판에만 있는 24개는 역 개명(신경주 → 경주)과 새 노선(중부내륙선 문경 연장 등) 때문이다. 2023년 출장에 2025년판 운임표를 쓰는 것이 타당하다는 확인이다.
- **정차역 수에 따른 금액 차이**(2026-11-17, 사용자 제공 기준 + 실제 자료 확인): 같은 구간·좌석이라도 열차의 중간 정차역 수에 따라 금액이 다르다. 운임표 금액에서 파생시켜 함께 둔다.
  - 중간 정차역 4개부터 1개당 0.2% 할인 → 0.2~1.0%(5단계). **일반실과 특실 모두** 깎인다(사용자 확인).
    100원 단위 처리(버림·사사오입)가 확인되지 않아 두 값을 모두 둔다(39,000의 0.6% = 38,766 → 38,700 또는 38,800).
  - **적용 범위**(2026-11-17 정정): 이 할인은 SRT 와 통합 뒤(2026-09-01~) KTX 에만 쓴다. 통합 전 KTX 는 운임표 주석의 **"도중 정차역 2개 이하 열차는 운임·요금의 0.6% 할증"** 만 쓴다.
    처음에는 통합 전 KTX 에도 할인 사다리를 적용했는데(D 2,900건), 문서에 없는 규칙이라 걷어냈다(D 3,306건 · 합계 650.1t → 650.7t).
    걷어내면서 못 풀게 된 금액은 39,900(18건) · 43,000(14건) · 61,100(12건)처럼 작게 흩어져 있다.
  - **특실 = 운임표의 특실 금액 + 일반실 금액 × 1.4**(특실요금 = 운임의 40%, 100원 단위). 할증·할인이 붙은 일반실에서도 다시 계산한다.
    이것으로 통합 전 특실 금액이 풀렸다: 60,800 = 43,400(43,100 + 0.6% 할증) × 1.4 (104건) · 60,600 = 오송 환승 43,300 × 1.4 (47건) · 57,500 = 광명 경유 할증분 × 1.4 (44건).
- **좌석 종류**(2026-11-17): 입석 = 일반실 좌석운임의 15% 할인, 자유석 = 5% 할인(코레일 운임 안내).
  - 파생 범위를 두 가지로 좁혔다(2026-11-17, 사용자 지적 "대구–서울 입석이 29,200이냐"): **정차역 할인 전 금액에서만**, 그리고 **그 역쌍의 대표 운임(가장 높은 일반실 운임)의 90% 이상인 행에서만** 파생시킨다.
    동대구–서울 34,500원은 수원 경유 완행 KTX 운임이라 여기서 입석(29,200)을 만들면 우연히 맞는 금액이 늘어난다. 대구–서울 입석은 43,500 × 0.85 = 36,900원이다.
  - 셋을 비교해 마지막을 골랐다(대구–서울 임의 금액 851가지 중 조합으로 설명되는 비율 / 실제 자료 일치율): 정차역 할인에도 겹쳐 쓰기 56% / 97.0% · 대표 운임 제한 없이 51% / 96.4% · **현재 49% / 96.2%**.
    세 가지의 신호 대 잡음은 비슷하지만, 현재 설정이 가장 설명이 그럴듯하다(61,800 = SRT 서대구↔수서 30,900 입석 왕복, 62,600 = 동대구·서대구 입석 왕복).
  - 46,900원(대구→세종 1,480건)은 KTX 24,800 + SRT 22,100(정차역 할인)으로 풀렸다. 48,400원은 24,800 + 23,600(자유석), 40,000원은 좌석 + 입석 왕복이다.
  - 기관이 준 판정기준표의 "SRT 대구권→수서 36,900~37,300원" 다섯 값은 SRT 동대구–수서 37,400원의 정차역 할인 사다리와 일치한다(정차역 모델의 교차 확인).
  - 파생 단계(`dk`)를 두어 **운임표 금액 그대로인 설명을 먼저** 본다(0 = 표 그대로, 정차역 1~5, 좌석 종류 +9).
    가는 편·오는 편의 좌석 종류가 다른 조합(입석 + 좌석)과 두 편 모두 입석·자유석인 조합까지 인정한다(2026-11-17 사용자 확인: 둘 다 실제로 있음).
    실제 자료에서 좌석 종류 가정이 들어간 행은 1,301건이고, 그 가운데 두 편 모두 입석·자유석인 행은 약 130건이다.
  - **우연 일치 검사**(2026-11-17): 대구–서울 구간에서 15,000~100,000원의 모든 금액(851가지) 중 조합으로 "설명"되는 비율은 좌석·특실만 쓸 때 40%, 입석·자유석까지 쓰면 49%다.
    실제 자료의 일치율은 95.0% → 96.2%이므로, 입석·자유석으로 새로 맞은 행 가운데 3분의 1 정도는 우연일 수 있다. 거리는 구간 공식거리에서 오므로 배출량 영향은 작지만(편도↔왕복이 뒤집힐 때만 2배),
    등급 B 를 근거로 쓸 때는 "(좌석 종류 가정)" 표시를 함께 봐야 한다. 더 좁히려면 승차권 종류가 적힌 자료가 필요하다.
  - 좌석 종류를 가정해 맞춘 행은 등급 글자에 "(좌석 종류 가정)"을 붙인다. 실제 자료에서 1,301건이다.
  - 옛 기준표의 SRT 표에 섞여 있던 서울·광명 착발 행은 통합 뒤 운임이므로 8월까지의 기간에는 쓰지 않는다.
  - 장소로 구간을 못 가릴 때(C)와 운임 대조에서는 운임표 금액 그대로인 후보를 변형 후보보다 먼저 본다.
- **후보가 여럿일 때 고르는 순서**(2026-11-17): ① 같은 도시로 적힌 행은 본원(대구)과의 구간 → ② 대표역(서울·동대구 / 광명·영등포·용산·서대구는 부역) → ③ 운임표 금액 그대로(`dk` 0) → ④ 편도 한 장 → 같은 구간 왕복 → 서로 다른 두 구간 왕복.
