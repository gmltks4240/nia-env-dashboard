## 무엇을 만드는가

출장 엑셀을 올리면 Scope 3 카테고리 6(출장) 배출량을 자동 산정하는 기능. 용도는 **대외 공시·검증 대응**이라 건별 근거가 남아야 한다.
지금 구현된 것은 **철도뿐**이다.

## 확정된 규칙 (사용자와 합의)

- 한 행 = 출장 1건(1인), 기본 왕복 1회. **상한은 아니다**(2026-11-17 사용자 정정): 교통비가 왕복 운임의 n배이고 출장 일수가 n일 이상이면 왕복 n회, 일수가 모자라거나 모르면 일수만큼만 산정하고 "횟수 확인 필요" 표시. "현재 수치" 표는 이 변경 전 값이라 원본 파일로 다시 내야 한다
- 교통비가 구간 왕복 운임의 절반 수준이면 편도
- 교통비 0원 = 미이동, 제외
- 특실은 임원 등 극히 일부. 계수는 좌석 구분 없음
- 공용차량 제외(Scope 1과 이중계상), 차량동승 0
- 철도 계수: 0.0219 kgCO₂eq/인·km, 강릉선 0.0716 (기관 협의값). 강릉선 행은 역을 추정해 서울까지는 0.0219, 서울–강릉선 역만 0.0716 (2026-11-17 사용자 요청, 설계서 §3.5)
- 장소로 구분이 안 되면 운임과 대조한다. 운임으로 장소를 자동 지정하지는 않는다(검산에만 사용)
- AI는 장소 분류만. 거리·배출량은 규칙으로 계산
- **AI 자동 호출은 쓰지 않기로 함.** 새 파일이 오면 대화에서 분류해 사전에 넣는다(아래 "새 파일이 올 때")
- 자가차량은 "유종별 주행거리 × 계수"로 하기로 함(미구현, 파일에 유종 칸이 없어 출처를 정해야 함)

## 새 파일이 올 때 (AI 자동 호출 없이)

1. 사용자가 대시보드에 올리고 "검토표 CSV"를 내려받아 대화에 올린다
2. `출처`가 `없음`인 장소를 아래 기준으로 분류한다
3. `trip_places`에 넣는 SQL(`source = 'ai'`, `on conflict … where source = 'ai'`)과 검토용 엑셀을 만들어 준다

분류 기준:

- 선택지는 `TRIP_POINTS` 25개. 철도로 타고 내리는 거점 도시로 분류
- 수도권(경기·인천 포함)은 서울. 단 SRT 동탄·평택지제 권역(동탄·평택·오산·안성·화성)은 거점 없음
- 세종청사 부처, 청주·오송·오창은 세종. 정부대전청사·대덕 연구기관은 대전. 경산은 대구
- 원주·춘천, 충남 서부, 충북 북부 등 목록에 거점이 없는 곳은 "거점 없음"(`points` 비움, 확신 high/low)
- 모르면 지어내지 말고 "모름"(`points` 비움, `confidence = 'unknown'`)
- 장소 이름만 보고 분류하고, 운임 대조는 분류한 뒤에 한다. 확신이 낮은데 운임이 다른 곳을 가리키면 "모름"으로 내린다

## 사용자에게 설명할 때 주의

- 근거를 묶어서 쓰면 이해하지 못한다. 장소마다 "무엇을 보고 판단했는지"와 "실제 출장 기록·교통비"를 함께 보여 줘야 한다
- 철도 범위라고 정했으면 다른 교통편 기록을 섞지 않는다
- 완료된 것과 가정한 것을 구분해 말한다(자기소개서용 정리에서 여러 번 문제가 됨)
- 내부 자료의 건수를 외부 문서에 쓰는 것은 사용자가 확인해야 한다
